# 外贸报价计算器（Foreign Trade Quote Calculator）

[![CI](https://github.com/linklee35-star/foreign-trade-calculator/actions/workflows/ci.yml/badge.svg)](https://github.com/linklee35-star/foreign-trade-calculator/actions/workflows/ci.yml)

给外贸业务员 / SOHO / 工厂用的报价测算工具：输入采购价与费用，直接得出 **FOB / CFR / CIF 报价、退税收入、换汇成本、整单利润**。

🌐 **在线使用（无需安装）**：https://linklee35-star.github.io/foreign-trade-calculator/

> 外贸报价最容易出错的不是算术，是**口径**：退税按不含税价算、保险费按 CIF 加成算、换汇成本要跟银行汇率比。这个工具把这些口径固化进公式，并在界面上写明。

## ✨ 功能

- **多货号明细**：一张订单多个货号，每个货号按自己的 HS 编码退税率**单独退税**，不共用全单一个税率
- **费用分摊**：国内费用 / 海运费 / 保险费按「货值」或「数量」分摊到每个货号，输出每行 CIF 单价——哪个货号吃掉成本一眼可见
- **FOB / CFR / CIF 三级成本**：按 Incoterms 2020 口径递进；**报价基数跟随所选术语**（不是永远按 CIF 报）
- **CIF 保险费**：按「保险加成 × 保险费率」反解，不是简单相加
- **换汇成本**：外贸核心指标，固定按 FOB 口径与银行汇率对比，判断有没有利润
- **客户报价单**：一键生成打印 / PDF 版报价单（品名 / 规格 / 数量 / 单价 / 金额 + 术语 + 有效期 + 付款方式），**报价单不含任何成本信息**
- **成本拆解**：整单成本按项目拆开（采购 / 退税冲减 / 国内费用 / 海运 / 保险），统一折人民币便于横向比较
- **输入自动保存**：刷新不丢，多货号也不丢
- **纯前端**：数据只在浏览器，无后端、无账号、可离线

## 🧮 计算口径（公式全公开）

```
不含税采购额 = 含税采购总额 ÷ (1 + 增值税率)
退税收入     = 不含税采购额 × 该货号退税率      ← 逐货号计算
FOB 成本     = 含税采购总额 − 退税收入 + 国内费用
CFR 成本     = FOB 成本 + 海运费
CIF 成本     = CFR 成本 ÷ (1 − 保险加成 × 保险费率)
报价         = 所选术语成本 × (1 + 目标利润率)   ← FOB / CFR / CIF 三选一
换汇成本     = FOB 人民币成本 ÷ FOB 美元报价     ← 固定 FOB 口径
```

**费用分摊**：国内费用 + 海运费 + 保险费先汇总成费用池，再按货值（或数量）占比分到每个货号，
因此「各行 CIF 成本之和 = 整单 CIF 成本」（有单测守着这个不变量）。

**没有货就没有订单**：总数量为 0 时全部金额归零——固定费用不会被算成一份"零件的报价"。

> 退税率按 **HS 编码**确定，各国/各类目不同，工具不内置税率表——请按海关最新退税率手册填写。
> 出口退税需取得**增值税专用发票**并满足退税条件。

## 🚀 本地运行

```bash
npm install
npm run dev      # 开发
npm test         # 单测（vitest）
npm run build    # 构建（tsc + vite build）
```

## ☁️ 部署

构建产物为纯静态（`base: "./"`），可直接放 GitHub Pages / Vercel / 对象存储 / 内网 Nginx。

## 📁 目录结构

```
src/lib/quote.ts        计算引擎（纯函数，零依赖，全部可单测）
src/lib/breakdown.ts    成本拆解（明细行加总必须等于 CIF 成本）
src/lib/storage.ts      输入持久化（注入式 Storage，单测无需 jsdom）
src/lib/defaults.ts     默认输入与货号 id 生成
src/lib/types.ts        输入/输出类型
src/lib/*.test.ts       单测（31 个：退税基数 / 多货号退税 / 费用分摊 / 术语切换 / 换汇成本 / 持久化 / 边界）
src/App.tsx             界面（明细编辑 + 结果面板 + 打印版报价单）
```
